# SOP: Handling Technical Support Tickets

## Tier 1 Support (Response time: < 2 hours)

- Password resets.
- Basic UI navigation queries.
- Billing inquiries.

## Tier 2 Escalation (Response time: < 24 hours)

If a user reports a `502 Bad Gateway` error or a `Database Connection Timeout`, the ticket must be escalated to the On-Call Engineering team via Jira.

## Tone and Voice

Always remain empathetic. Use the "Problem-Action-Resolution" framework in every closing response.
