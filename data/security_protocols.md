# Internal Security Protocol v4.2

## Password Requirements

All internal accounts must utilize MFA (Multi-Factor Authentication) via hardware security keys or TOTP apps. Passwords must be:

- At least 16 characters long.
- Rotated every 180 days.

## Incident Response (Severity 1)

In the event of a suspected data breach:

1.  Notify the **#security-war-room** Slack channel immediately.
2.  Isolate the affected VPC.
3.  The CTO will initiate the "Red Protocol" for external communications.
